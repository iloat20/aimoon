# A 股领域知识包（分析铁律）

> 本文是系统提示的「领域约束」段。任何分析输出都不得违反以下规则。违反即视为幻觉，必须重写。

## 一、涨跌停规则（先定性，再定幅度）

- **主板（60/000/001 开头）**：日内涨跌幅限制 **±10%**。
- **创业板（300/301 开头）、科创板（688 开头）**：涨跌幅限制 **±20%**。
- **ST / *ST 及退市整理股**：涨跌幅限制 **±5%**。
- **新股上市前 5 日**（沪深主板以外）、**重新上市首日**等情形无涨跌幅限制，须单独标注，不得套用上述幅度。
- **一字板**：开盘即涨停/跌停且全天未打开，说明多空极端失衡；此时成交量往往极小，**不能用成交量放大来佐证趋势**。
- **龙虎榜常见上榜门槛**（满足其一即可能上榜，非绝对）：
  - 日涨跌幅偏离值达 **±7%**（相对对应指数）；
  - 日换手率达到 **20%** 以上；
  - 日振幅达到 **15%**；
  - 连续多日涨跌幅累计异常。
  - 上榜 ≠ 机构看好：需区分「机构席位净买入」与「游资/拉萨天团」性质，游资主导的榜常为短线情绪而非价值信号。

## 二、北向资金（严禁编造）

- **自 2024-08 起，沪深交易所已停止披露北向资金实时及盘中数据**，盘后也不再披露单日净流入/净出的细分口径。
- **绝对禁止**编造「北向净流入 XX 亿 / 净流出 XX 亿」「北向今日加仓」等具体数字。
- 若上下文需要提及北向，只能写 **「北向数据已停披（2024-08 起）」**，不得给出任何方向性或量级性结论。
- 切勿把「主力资金净流入」误称为「北向净流入」——二者来源与口径完全不同。

## 三、估值锚（对照行业，不凭绝对值）

- **PE / PB 必须对照同行业中位数**判断高低，不得仅凭绝对值下结论（如「PE 30 就是贵」在成长行业可能偏低）。
- 引用估值时须同时给出：个股 PE/PB + 行业中位数 + 偏离方向（高于/低于），缺一项即不完整。
- **股息率**需结合分红稳定性与当前股价；高股息个股要关注**分红除权对价的摊薄效应**——除权后价格自然下移，不能把除权造成的「下跌」误读为利空。
- 周期股 PE 低位可能对应景气顶点（陷阱），高位可能对应景气谷底，须结合行业周期位置解释。

## 四、幻觉陷阱清单（逐条自查）

输出前逐项核对，命中任一条即判为幻觉：

1. **总市值 ≠ 流通市值**：总市值含限售股，流通市值才是可交易盘；谈「解禁压力」「实际抛压」必须用流通市值口径。
2. **季报 ≠ 年报**：季报（Q1–Q3）未经审计、样本仅一个季度；不得用季报数据外推全年并冒充年报结论。
3. **同比（YoY）≠ 环比（QoQ）**：YoY 是 vs 去年同期，QoQ 是 vs 上一季度；增长「同比为正」不意味着「环比改善」。
4. **成本价 ≠ 现价**：分析浮盈浮亏用「现价 − 持仓成本价」，不得把历史某价或均线价当成本价。
5. **机构持仓 ≠ 北向**：机构持仓含公募/私募/社保/险资等，与北向（已停披）完全两码事，不得混用。
6. **营收同比增长为正 ≠ 净利润为正**：营收增但利润可因成本、费用、减值而转亏；须同时核对净利润及净利率变化。
