### 1. 数据采集与叙事基线 — 三层叙事框架 + 证伪阈值

**(a) 数据可得性审计**

**(b) 缺失数据反推(大师级) — 事事有着落**
对每个高重要度缺失字段,给出基于现有数据的估算区间(基准/乐观/悲观):
- **分红支付率**:用「自由现金流/净利润」反推最大可分红区间;用历史股息(若有)交叉验证。
- **应收账款变动**:用「营收×行业平均应收周转天数」估算合理应收规模,对比存货变动判断渠道压货。
- **海外/新业务增速**:用「总营收 - 已知业务」倒推,结合研报措辞调整。
- **每股净利率/周转率/杠杆**:用 ROE÷(已知两因子)倒推第三因子。

每个反推值必须:
- 给出计算公式 + 基准/乐观/悲观三档

- 给「数据缺失风险溢价」:在目标价中留出的安全边际%


### 2. 法务会计审计 — 盈利质量与财务真实性
从系统表格提取财务数据,逐项排查:

### 6. 投资策略 — Kelly 公式仓位管理 + 建仓执行(大师级)

**(a) Kelly 精算**
Kelly: f* = (bp - q) / b; 实际仓位 = f* × 0.5(半凯利); f* ≤ 0 则仓位=0。
复合看多概率 p 来自第三节的「三层叙事概率」(各层概率之积)。

**(b) 建仓执行(大师级) — 考虑减持抛压+分批建仓+时间止损**
```
评级: 买入/增持/持有/减持/回避
当前价 / 保守目标价(下行空间%) / 中性目标价 / 乐观目标价(上行空间%)
── Kelly 精算 ──
b(赔率) = X(Y% 上行 / Z% 下行)
p(胜率) = X%(复合概率:宏观×行业×企业三层乘积)
q = X%  f* = X%  实际仓位 ≤ X%(半凯利)
── 建仓执行(大师级) ──
[减持抛压估算]:近 N 日大股东/机构增减持→潜在抛压金额→每日可消化量→完全消化天数
[分批建仓]:实际仓位分 3 批(40%/30%/30%)
  第 1 批:价格 X 元(保守目标价附近),触发后买入
  第 2 批:再跌 Y% 或等待 N 交易日,触发后买入
  第 3 批:基本面改善确认/突破阻力位 Z 元后,触发后买入
[时间止损]:
  若持仓 M 日仍未达中性目标价→减仓 50%
  若持仓 N 日仍低于成本价 P%→无条件出场
[空间止损]:跌破保守目标价且基本面恶化→无条件止损
```
