## 二、P0 — 立即修复（高影响 + 低工作量）

### 2.1 修复 5 个失败测试（无 CI 防护，regression 已潜伏）

**问题**: 项目无 CI 无 pre-commit，5 个测试失败无人发现：
- `test_tools_valuation.py` — 2 个 TypeError（valuation 返回结构变更，`dict` vs `float`）
- `test_pipeline_tables.py` — EPS 值在渲染中被除以 1e8 变成 0.00
- `test_orchestrator_wiring.py` — 2 个 wiring 测试失败
- `test_collector_baseline.py` — sina fallback 测试失败

**修复**: 逐一排查，对齐测试与当前代码结构。
**工作量**: ~2h | **影响**: 防止 regression 继续积累

### 2.2 wechat.py 固定 sleep 8s → 事件驱动等待

**文件**: `src/aimoon/adapters/driven/collectors/wechat.py:54-61`
**问题**: 4 次页面导航，每次后 `wait_for_timeout(2000)` = 8 秒纯等待。
**修复**: 替换为 `wait_for_selector("ul.news-list li", timeout=...)`。
**工作量**: ~30min | **收益**: 节省 6-7 秒

### 2.3 akshare 三大表 API 重复调用 3 次

**文件**: `src/aimoon/adapters/driven/financial/akshare_adapter.py`
**问题**: `fetch()` 有 24h 缓存，但 `fetch_quarterly()` 和 `fetch_history()` **无缓存**，重复请求相同 API。
**修复**: `fetch_quarterly` 从 `fetch()` 的缓存 DataFrame 过滤；`fetch_history` 复用 `fetch()` 已拉取的数据。
**工作量**: ~1h | **收益**: 节省 3-8 秒 + 减少 API 压力

### 2.4 配置 integration marker 默认过滤

**文件**: `pyproject.toml`
**问题**: `integration` marker 已注册但无默认过滤，离线环境跑测试会失败。
**修复**: 添加 `addopts = "-m 'not integration'"`。
**工作量**: ~5min | **影响**: 测试可在离线环境正确运行
