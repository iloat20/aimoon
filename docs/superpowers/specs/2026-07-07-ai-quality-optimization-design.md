# 子项目2: AI 质量优化 — 增强 Prompt 约束

日期: 2026-07-07
状态: 已批准

## 问题

ANALYSIS 初稿定性描述多、硬数据少;COMPILE 终稿偶有引入上游不存在的"幻觉数字"。

## 方案

纯 prompt 约束增强,零代码改动。

### analysis.md 增加 3 条

在 `**关键规则**` 区块末尾追加:

```
- 每个章节至少引用 3 个硬数据点(具体金额/比率/同比增速/同行对比值),无数据时明确标注"数据缺失"。
- 定性结论必须有量化支撑:"表现良好"→"营收 CAGR 15.2%,高于行业中位数 8.7%"。
- 禁止使用模糊修饰词替代数字(如"较高""显著""大幅"),必须给出具体数值。
```

### compile.md 增加 2 条

在 `**最终约束**` 区块末尾追加:

```
- **数字忠实性**: 终稿所有数字必须来源于 ANALYSIS 初稿、已渲染表格或工具输出,禁止引入上游不存在的新数字。
- 若某数字无法溯源,删除该句而非编造。
```

## 影响

- 文件: `prompts/analysis.md`、`prompts/compile.md`
- 代码: 无
- 测试: 无需修改(section_coverage 不涉及数字密度)
- 成本: 零额外 tokens(prompt 增加约 150 字符,可忽略)

## 验证

人工跑一次 `aimoon 600519`,检查:
1. 每个章节是否有 ≥3 个硬数据点
2. 终稿数字是否均可溯源到初稿/表格
