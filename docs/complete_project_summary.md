## 🔧 技术改进

### 1. 入场逻辑改进
```
修复前:
- 入场阈值: 18（0-100尺度无意义）
- 无确认过滤器
- 反转奖励: 任何-5%都给+5分

修复后:
- 入场阈值: 55（有意义的高质量入口）
- 多信号确认（≥2个因子组）
- 反转奖励: 需2日ROC稳定确认
```

### 2. 退出逻辑改进
```
修复前:
- 止损: 固定4%（太紧，频繁假止损）
- 追踪止损: +3%锁利，+6%锁+3%
- 无利润保护
- 无动量延期

修复后:
- 止损: ATR 2.0倍 [4%, 8%]（自适应）
- 追踪止损: +2%保本，+5%追踪50%，+10%追踪40%
- 利润保护: 峰值≥5%且回落≤1%退出
- 动量延期: 评分维持≥80%且收益>0
```

### 3. 仓位管理改进
```
修复前:
- 等权仓位分配
- 行业集中限制: 30%
- 无Regime适应

修复后:
- 分数比例仓位（高分股更大仓位）
- 行业集中限制: 25%
- Regime自适应（熊市/高波动/牛市）
```

## 📊 实盘模拟系统

### 系统特点
| 特点 | 说明 |
|------|------|
| **无风险** | 不使用真实资金，完全模拟 |
| **真实成本** | 包含手续费、滑点、印花税 |
| **持久化** | 自动保存交易记录和持仓 |
| **完整风控** | 优化后的止损/止盈/追踪策略 |
| **易于使用** | 命令行界面，快速上手 |

### 使用方法
```bash
# 1. 运行演示
python -m aimoon.paper_trading_example

# 2. 查看持仓
python -m aimoon.paper_trading_demo --positions

# 3. 生成报告
python -m aimoon.paper_trading_demo --report
```

### 风控机制
- ✅ 止损: 6%（ATR自适应[4%, 8%]）
- ✅ 止盈: 15%
- ✅ 追踪止损: +5%追踪峰值50%
- ✅ 利润保护: 峰值≥5%且收益回落≤1%
- ✅ 动量退出: 评分<33分
- ✅ 行业限制: 单行业≤25%
