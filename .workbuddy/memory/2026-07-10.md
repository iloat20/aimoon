## AI 分析流程重构 brainstorming（设计完成，待实施）
深入审查 AI 分析 pipeline，发现 6 个核心问题：①ANALYSIS+COMPILE 双阶段重复生成（COMPILE prompt 明确要求不沿用草稿重写）②SELF_CHECK 章节校验 bug（检查8节但ANALYSIS只出4节）③SELF_CHECK 伪修复（无修复LLM调用，只提示）④工具批次串行浪费（fcf 困在批3等val）⑤降级双重成本（v2失败→legacy再调一次）⑥COMPILE prompt 自相矛盾。

用户选定：**综合重构 + 方案B（骨架+扩写）+ JSON Schema**。

### 设计方案
- ANALYSIS 输出结构化 JSON 骨架（推理结论+数字+逻辑链），不写完整文章。reasoning_effort=high, max_tokens 8192→4096。
- SELF_CHECK 改为纯 Python 程序化校验（0 LLM）：格式/数学一致性(Kelly公式/概率乘积)/数字比对/必填。
- COMPILE 基于骨架纯扩写，禁止重新推理。
- 降级：任何阶段失败都不再调 LLM，改为骨架+表格模板渲染。
- 工具批次优化：3批→2批（asyncio.create_task 依赖触发，fcf 提前到批2）。

### 预期收益
token -45%，耗时 -40%，降级 0 LLM。
