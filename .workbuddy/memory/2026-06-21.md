- **财报**: pysnowball 适配器, 资产负债表+利润表+现金流+指标
  - 实测 600519: 营收547亿(+6.34%), 净利272亿(+1.47%), ROE 10.57%, EPS 21.76
  - 数据格式: [value, yoy_ratio] pair, 英文key名
- **社交**: 8个平台采集器
  - 雪球: stock.xueqiu.com 热帖API (bypass WAF) + xueqiu.com hot list
  - 东方财富股吧: Selenium 优先 → akshare 兜底, 实测20条

  - 微信公众号: 搜狗微信搜索, 实测10条
  - 小红书: Playwright实现, 需运行 login() 扫码登录
  - 抖音: Playwright实现, 需运行 login() 扫码登录
- **AI分析**: DeepSeek API (sk-9ab...), 6维度分析, JSON结构化输出, 容错重试
- **报告**: Jinja2模板, 深蓝暗色主题, 响应式布局, 红涨绿跌配色
- **数据质量**: 格式校验+交叉验证+时效性检查

- pysnowball token = 完整Cookie字符串（非仅xq_a_token值）
